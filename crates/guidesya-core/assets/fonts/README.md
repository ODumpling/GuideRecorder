# Bundled fonts

Used by `guidesya_core::export` to draw callout text. Only these fonts are
loaded (never system fonts), so rendered images are the same on every machine.

| File | Font | Version | Licence | SHA-256 |
|---|---|---|---|---|
| `Lato-Regular.ttf` | Lato Regular, by Łukasz Dziedzic (tyPoland) | 2.015 (2015-08-06) | SIL Open Font License 1.1, see `Lato-OFL.txt` | `d636e4683231f931eda222d588e944d082bfd3bdba02f928bee461c0f185b251` |

Source: <https://github.com/google/fonts/tree/main/ofl/lato>. The font is
bundled unmodified, under its own name ("Lato" is a Reserved Font Name, so a
modified version would have to be renamed).
